# Historical team logos

Place **owned or clearly licensed** historical NBA team marks here.

## Rules

- Do **not** scrape logos from the web to fill gaps.
- Do **not** register an asset in code until the file is committed here.
- Prefer small optimized SVG/WebP with fixed intrinsic size.

## Registration

After adding a file, register it in `src/lib/historical-team-brand.ts` → `HISTORICAL_TEAM_LOGO_ASSETS`:

```ts
"25:SEA": { path: "/logos/historical/sea-1970s.svg", label: "Seattle SuperSonics" },
```

Until registered, Time Machine uses **text marks** (name + abbreviation) rather than modern franchise CDN art.
