# Player page before / after

## Before (human review)

Left rail competed as:

- orientation
- DRBL summary (DRBL/100, rank, percentile, Wins Above R1)
- R1 Points / P1 methodology disclosure
- P / LN / B diagnostics
- duplicated StatDisclosure of DRBL/100
- career vs season box rates
- season rates
- ASK
- recent seasons

First view required model vocabulary (R1, P/LN/B) before “how good.”

## After

Left rail orients:

1. Player identity strip (season · team)
2. **DRBL** simple card:
   - human grade (Elite / Great / Good / …)
   - plain “Estimated impact per 100 possessions” + percentile
   - **DRBL/100** + **Wins Above R1** only as headlines
   - **Offense** / **Defense** as casual labels
   - single deepen link: “Why does DRBL rate him this way?”
3. Familiar box-score context (vs career + season rates) — visually secondary
4. ASK + recent seasons remain, below the simple DRBL read

Removed from first view:

- Rank (#N)
- R1 Points / P1
- P / LN / B disclosures
- Duplicate DRBL StatDisclosure when DRBL is present

Analytical profile:

- Overview (was Value): DRBL/100, Wins Above R1, Offense, Defense (+ external impact)
- Advanced: DRBL-P / LN / B + ratings

## Five-second test target

Player · team/season · quality label · DRBL/100 · Wins Above R1 — without R1/EB/P/LN/B jargon.
