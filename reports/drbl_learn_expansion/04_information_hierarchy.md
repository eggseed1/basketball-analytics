# Information hierarchy

```text
SIMPLE SURFACE
  who / team / season
  interpretation (grade)
  DRBL/100
  Wins Above R1
  Offense / Defense (optional split)
  → Why? (Learn)

ORIENTATION CONTEXT
  box rates
  recent seasons
  ASK

EXPLORE (Analytical profile)
  Overview → Offense → Shooting → Defense → Role → Advanced

DEEP RABBIT HOLE (/learn)
  portal /learn/drbl
  metric guides (StatGuide)
  systems topics (how / validation / historical / limitations)
```

Ladder:

| Depth | Form |
|-------|------|
| Tooltip | one sentence |
| Overview portal | ~1 minute |
| Dedicated Learn page | 5–15 minutes |
| Research seals | deepest |
